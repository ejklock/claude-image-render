Living-docs bundle for **`claude-image-render`** (the plugin `image-render`; local folder still `claude-image-mod`): a Claude Code mod that shows in the terminal the images the agent reads (a `Read` of a PNG or JPG, a screenshot), as the pi agent does. Started on 2026-11-02.
